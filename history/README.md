# Superseded artifacts

Files here are preserved for design history, not current specifications. Option1–5 images show earlier EXTERIOR clearance studies without current lining/baffles/roof details. Options6–8 were removed at user request. Pre-lining airflow files describe6.50ft2 and1,524fpm, superseded by5.713ft2 and1,733fpm.

`scripts/` contains original one-off Blender scripts. They often resolve paths from their original directory, depend on missing intermediate revisions, and overwrite filenames. They are archival reference, not executable portable tools. Start new work from models/XLR8-all-options-toggle.blend and use tools/ for supported review operations.
