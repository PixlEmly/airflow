## Evolution

1. User sought easier tools than SolidWorks/Illustrator for 3D discussion of a wall-mounted sound-deflection box. SketchUp Make 2017 was explored initially; later mesh/reference work and editable option scenes were produced in Blender. SketchUp import is not a final requirement.
2. Polycam Business trial scans were supplied in multiple formats. Scan was taken in Space mode. Nominal 6in and 10in vents provide reference dimensions but do not certify scan scale. Source location originally Z:\Projects\XLR8\silencing; newer scan supplied as 11_7_2026.zip from a network share. Local copies are included as OBJ + MTL + textures.
3. Initial concept: box extends to soffit, bottom about 1ft above ground, winding air path through alternating baffles. User sketches show the side section and building/roof/hot-gas routing concept. Tree prevents a straight full-depth box along the whole wall.
4. User clarified the small circular openings are LEFT of the large square hood; there is an additional hood farther left containing another 10in vent. Old scan was incomplete; a new scan was supplied. Final tree envelope must combine both scans because each showed only part of the trunk.
5. User favored ending/capping the box at the tree rather than curving around it. Baffles are NOT exterior accessible storage shelves. They are internal, about half-depth, with top/bottom attached to outer wall and middle attached to building wall. Earlier inside/outside/inside arrangements are superseded.
6. Explored reducing width/depth or raising base to avoid complex tree cutouts. Options 1–5 compare depth/base-height changes. Options 6–8 later explored width/corner changes. All needed to share identical coordinates in ONE file and be toggled in place.
7. User removed options 6, 7, 8. Added shared exhaust hardware from the separate 6in duct next to square vent: round 90 elbow, silencer and rain cover. Reference screenshot gives LD6 row dimensions interpreted as 6 / 10.25 / 23.625in.
8. Roof fragments out.obj/out2.obj and full roof scan were supplied. Square wedge body identifies hood. User requested clean plane from top of soffit edge, same soffit width, extending inward 10ft; ignore broken geometry and giant irrelevant plane. A provisional 2:12 slope was replaced by averaging corrugated/white patches, aligned to existing modeled front. Fit is weak and explicitly provisional.
9. Silencer was lowered into roof on lower elbow. Initial upper cover suggestion was beyond 90, about 120 degrees; user subsequently selected short-radius 90-degree pipe aimed inward. Square roof protrusion/chase then extended to conceal the entire large silencer body, with just reduced connector and top elbow outside.
10. User selected Option 4 provisionally, keeping other options present but hidden, and requested baffles. User confirmed three main outlets at approximately 3,300 CFM EACH; this overstates actual flow for buffer. No fan static pressure is available. Six-inch route is separate.
11. First Option 4 baffles used 80mm lined envelopes and about 9.86in half-depth gaps, nominal 6.50ft2 passages and 1,524fpm at 9,900CFM. Outside/inside/outside orientation was retained after comparison: inferred better inlet alignment with hood discharge; opposite may ease outward bottom escape, but neither demonstrated superior pressure/acoustic results.
12. User requested allowance for 1in FRK interior surfaces. Model now includes 1in lining on enclosure interior, baffle faces and tips. Baffle core shrunk within the original 80mm total thickness. Lined width 92.88in, lined depth 17.71in, tip/vertical gaps 8.86in, nominal area 5.713ft2, velocity 1,733fpm. User confirmed understanding that smaller underlying boards accommodate edge lining; enclosure walls do not grow outward, their lining consumes interior volume.
13. Discussion of restrictions: no zero-loss guarantee. 12% area reduction, 14% velocity increase and ~29% velocity-pressure increase at fixed flow. Hypothetical K=1/3/5 gives 0.19/0.56/0.94in water loss, NOT a predicted K range. Higher-base alternatives lose vertical room for three baffles and cannot be assumed better. Proposed next validation: temporary adjustable full-scale mockup, compare outlet flows/pressure and noise with fans individually and together.

User cloned repo into XLR8-scan-reference/airflow (not its parent). Empty main branch with origin set correctly was observed.
