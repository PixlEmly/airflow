# Provenance and exclusions

The package is assembled from the local XLR8-scan-reference project and user-attached sketches/product images. `COPY-PROVENANCE.json` records copies. `MANIFEST.json` checks packaged files. It is a point-in-time review snapshot dated 2026-11-08; original files remain unchanged outside the repository.

Included: authoritative combined Blender scene; old/new textured scan meshes and materials; full roof textured scan and small out/out2 fragments; aligned scan scene; tree envelope/registration/roof fits; user section/building sketches and supplied product screenshots where available; current visualizations and calculations; superseded option images; original Python modeling/measurement scripts.

Excluded intentionally: duplicate ZIP exports, point-cloud duplicate, routine Blender backup files, every intermediate full-scene revision, redundant inspection renders, unrelated chat projects. Existing editable scene and original scan meshes are sufficient for continued review; a complete from-scratch deterministic rebuild of historical steps is NOT supplied. Some historical scripts need those excluded intermediates and original machine paths.

Potentially confusing history: initial model used only the new scan and a tree recess; subsequent revisions combined both scans and adopted a straight end. Historical tree-overlap counts refer to that revision's box, not current option4. Historical options6–8 were removed. Older flow files precede one-inch wall lining. Old roof images may use a prior shell option. Use current model/current drawings for current decisions.

Raw scan filenames are preserved; both wall and roof scans have an 11_7_2026 filename in separate folders. Image references are supplied for discussion, not proof of product selection or suitability. Third-party copyrights remain with their respective owners; no project-wide license was inferred.

Repository access at packaging time: local repository available, origin set to PixlEmly/airflow, no commits initially. GitHub DNS resolution unavailable to the agent environment; remote write authorization not tested. No push performed.
